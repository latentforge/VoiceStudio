# OmniVoice

OmniVoice is a massively multilingual zero-shot text-to-speech model built on a diffusion-language-model-style architecture: a shared LLM backbone predicts masked multi-codebook audio tokens (an explicit audio mask token drives the iterative unmasking), with per-codebook audio embeddings and output heads on top of the backbone, supporting voice cloning and voice design.

Original model and code: [k2-fsa/OmniVoice](https://github.com/k2-fsa/OmniVoice)
