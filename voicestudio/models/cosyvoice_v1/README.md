# CosyVoice

CosyVoice is a scalable multilingual zero-shot text-to-speech synthesizer built on supervised semantic tokens: a text-to-token LLM predicts discrete speech tokens, a conditional flow matching module (with a DiT variant) converts those tokens to mel-spectrograms, and a HiFi-GAN vocoder renders the waveform.

Original model and code: [QwenAudio/CosyVoice](https://github.com/QwenAudio/CosyVoice)
