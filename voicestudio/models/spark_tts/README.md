# Spark TTS

Spark-TTS is an LLM-based text-to-speech model built on Qwen2.5 that predicts single-stream decoupled speech tokens (via BiCodec) directly, reconstructing audio from those tokens without a separate flow-matching or diffusion generation stage, and supports zero-shot, cross-lingual voice cloning with controllable speaker attributes.

Original model and code: [SparkAudio/Spark-TTS](https://github.com/SparkAudio/Spark-TTS)
